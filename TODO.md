# Delivery checklist

- [x] Functional Flask backend serves the browser application and JSON APIs.
- [x] Registration, login, logout, secure password hashing, and session-protected routes work.
- [x] Users can paste or upload unified Git diffs with size/type validation.
- [x] Modified, added, deleted, and renamed files are parsed and displayed.
- [x] AI generation returns three Conventional Commit suggestions with explanation and metadata.
- [x] Configurable OpenAI-compatible provider uses environment variables; demo mode is safe and explicit.
- [x] Suggestions support type, scope, length, regeneration, editing, and clipboard copy.
- [x] Generated messages persist per user with timestamps and searchable history.
- [x] Dashboard exposes totals, recent activity, and type statistics.
- [x] Dark/light theme and responsive sidebar dashboard are implemented.
- [x] Empty diffs, invalid uploads, oversized input, AI failures, and auth errors are handled.
- [x] Tests cover feature, bug-fix, docs, deleted/multiple files, validation, demo AI, and history behavior.
- [x] README, requirements, `.env.example`, and ZIP archive are provided.
